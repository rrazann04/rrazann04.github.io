Complaint Pulse

Project 01

US banking complaints from the Consumer Financial Protection Bureau · credit cards, bank accounts and mortgages · 2023 to 2025

  • SQL Server
  • Power BI
  • DAX
  • Data modeling
The question

Which products and companies get the most complaints, and how well do companies respond?

What I did

  1. Imported 479,026 records into SQL Server and checked every column first.
  2. Cleaned them down to 476,257 in-scope complaints and logged every rule.
  3. Built fact and dimension tables, then a three-page Power BI report with 20+ measures.

What I found

  • 99.4%of complaints were answered on time (on time doesn't mean solved)
  • +32.4%more complaints in 2025 than in 2024, led by bank accounts
  • 35.9%of all complaints went to the five largest companies

Ride Pulse

Project 02

Ride-hailing bookings across Delhi NCR · January to December 2024 · fares in Indian rupees

  • SQL Server
  • Power BI
  • DAX
  • Data cleaning
The question

Why do so many bookings fail, and when is demand highest?

The data is synthetic, so some splits are unusually even. The report says so.

What I did

  1. Loaded 150,000 bookings as text so the import couldn't fail, then fixed blanks, IDs and types.
  2. Checked 1,233 repeated booking IDs: they were different rides, so I kept them all.
  3. Built a two-page Power BI report with its own colour theme and synced filters.

What I found

  • 62%of bookings ended in a completed ride
  • 18%of bookings were cancelled by drivers, against 7% by customers
  • ₹47.3Min revenue from completed rides, with demand peaking at 5–7 pm

Superstore

Project 03

Retail orders across four US regions · 2014 to 2017

  • SQL Server
  • Power BI
  • Profit analysis
The question

Where does the store make money, and where does it lose it?

What I did

  1. Loaded the order data into SQL Server.
  2. Wrote queries for order counts, yearly sales and profit, and the effect of discounts on Tables.
  3. Built a two-page dashboard with year and region filters.

What I found

  • 12.47%profit margin on $2.30M in sales
  • $145Kprofit from Technology, the strongest category
  • −$18Klost on Tables, the weakest sub-category

How I work

My process

From raw file to decision
01

Profile

Look at every column first: row counts, blanks, odd values and repeated IDs.

02

Clean

Fix types and blanks in SQL, keep the raw data untouched, and log each rule.

03

Model

Build a star schema and check that every total matches the source.

04

Visualise

Design the dashboard around the questions people actually ask, with honest notes.
